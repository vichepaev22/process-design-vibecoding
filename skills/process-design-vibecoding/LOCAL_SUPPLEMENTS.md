# Package provenance

The initial main workflow was supplied to this project as `SKILL.md`. Its referenced supporting files were absent from that source package. The initial `references/`, `assets/`, and `scripts/` were created as local supplements on 2026-10-05; they are not recovered originals from an upstream author.

Version 1.1.0 adds canonical-spec change capture, request reconciliation, configurable document helpers, and a portable plugin package. This release does not include personal project files, chat transcripts, credentials, or machine-specific configuration.

Helper scripts create or check documents only. Structural and traceability checks do not establish semantic completeness, executed verification, or product readiness.

Version 1.2.0 adds the user-requested Context7 documentation checkpoint, installed-version compatibility checks, API-related debugging guidance and explicit unavailable-documentation handling. Context7 is supplied by the host, not bundled in this package.
