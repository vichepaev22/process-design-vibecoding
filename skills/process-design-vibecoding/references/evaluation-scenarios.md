# Сценарии самопроверки агента

## Однократный переход от прототипа к продукту — 1.5.0

| Ситуация | Ожидаемое поведение |
| --- | --- |
| Новый продукт, до первого релиза | Обсудить задачу, показать интерактивный прототип и получить отзыв; начальный этап сохраняется |
| Первый релиз или тестирование настоящего продукта, выбора ещё нет | Один раз спросить sync/product_only и записать ответ |
| Пользователь уже сказал «макет больше не обновлять» | Записать product_only без повторного вопроса |
| Вопрос уже задан, ответа пока нет | Оставить pending, не переспрашивать и не менять макет; продолжать независимую разрешённую работу в продукте |
| В product_only меняют текст, кнопки или порядок диалога | Менять и проверять продукт; не трогать прототип, не запускать его браузерные тесты/скриншоты и не требовать нового prototype gate |
| Выбран sync | Обновлять только затронутые состояния макета и продукта |
| В product_only отдельно попросили один экран макета | Выполнить только этот запрос, не включая постоянную синхронизацию |

Это ручная проверка непротиворечивости инструкций, не модельный бенчмарк.

Локальное дополнение от 2026-10-05, выведенное из пользовательского `SKILL.md`.

| Запрос/ситуация | Ожидаемое поведение |
| --- | --- |
| Создать новый сервис без ясной цели | Уточнить цель и существенные сценарии до реализации |
| Новый бот: понимание задачи уже есть | Краткий черновик сценария → кликабельный чат с тестовыми вложениями и основной ошибкой → показ и отзыв → уточнение ТЗ; не начинать с backend |
| Нужно экономить токены и быстро показать MVP | Один небольшой интерактивный вариант, несколько нужных состояний, без долгого выбора дизайна и инфраструктуры |
| Прототип только показан, отзыва нет | Не объявлять его принятым и не начинать основную реализацию; продолжать независимую разрешённую работу |
| Пользователь уже принял этот прототип, путь не меняется | Сослаться на принятое решение, не требовать повторного согласования и не пересобирать макет |
| Существенно меняется один путь существующего продукта | Прототипировать и согласовать только затронутый сценарий, сохраняя остальное |
| Внутренний backend/refactor без нового пользовательского пути | Записать неприменимость UI-прототипа; по необходимости показать наблюдаемый пример контракта |
| Есть только текстовое описание или картинка нового продукта | Не считать обязательный этап интерактивного прототипа выполненным |
| Ошибка/опечатка в уже принятом интерфейсе | Сокращённый/прямой процесс, без нового обязательного редизайна |
| Добавить функцию в существующий проект | Изучить код и текущие соглашения; описать изменение |
| Исправить воспроизводимую ошибку | Сокращённый цикл с регрессионной проверкой |
| Исправить опечатку | Прямая правка без набора проектных документов |
| Добавить роли или удаление данных | Определить существенные правила прав и удаления |
| Пользователь меняет требование | Сначала обновить главное ТЗ, затем приёмку, план и реализацию |
| Новая функция описана только в отдельном плане | Перенести действующее требование в главное ТЗ до реализации |
| Пользователь предлагает идею и откладывает другую | Сохранить разные статусы; не внедрять предложение и не терять отложенное |
| Тесты прошли, новое пожелание отсутствует в главном ТЗ | Не объявлять завершение; исправить документацию и сверить пожелания |
| Обычный ChatGPT не может изменить исходный документ | Выдать обновлённый файл/патч и явно назвать не обновлённый источник |
| Уже есть spec, план и AGENTS.md | Использовать и дополнять их, не заменять вслепую |
| Тест выявил проблему | Исправить реализацию, сохранив валидное требование |
| Внешняя система недоступна | Назвать непроверенный путь и доступное доказательство |
| Реализация использует библиотеку с установленной версией | Context7: проверить документацию и совместимость методов именно с этой версией |
| Ошибка может объясняться контрактом API | До выбора исправления проверить официальную документацию технологии через Context7 |
| Context7 или нужная версия документации недоступны | Сообщить ограничение, явно назвать официальный fallback, не угадывать API; зависимый неподтверждённый код отложить |
| Продолжить старый чат | Сохранить принятые решения и прочитать актуальные файлы |
| Простая локальная правка без неоднозначного сценария | Пропустить диаграмму; не вызывать отдельную модель для оценки |
| В ТЗ есть цепочка действий и внешний сервис | Коротко оценить пользу и предложить sequence для конкретного сценария; продолжать независимую работу |
| Диаграмма запрошена, отклонена или меняется сценарий | Запрошенную создать без повторного вопроса; отказ уважать; принятую схему обновить вместе с ТЗ, сохраняя статус и область проверки |

Перед завершением проверить, что заявленные команды реально выполнялись,
покрытие соответствует выводам и критерии приёмки не подменены наличием файлов.
