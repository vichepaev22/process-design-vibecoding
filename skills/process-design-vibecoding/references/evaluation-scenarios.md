# Сценарии самопроверки агента

Локальное дополнение от 2026-10-05, выведенное из пользовательского `SKILL.md`.

| Запрос/ситуация | Ожидаемое поведение |
| --- | --- |
| Создать новый сервис без ясной цели | Уточнить цель и существенные сценарии до реализации |
| Добавить функцию в существующий проект | Изучить код и текущие соглашения; описать изменение |
| Исправить воспроизводимую ошибку | Сокращённый цикл с регрессионной проверкой |
| Исправить опечатку | Прямая правка без набора проектных документов |
| Добавить роли или удаление данных | Определить существенные правила прав и удаления |
| Пользователь меняет требование | Сначала обновить главное ТЗ, затем приёмку, план и реализацию |
| Новая функция описана только в отдельном плане | Перенести действующее требование в главное ТЗ до реализации |
| Пользователь предлагает идею и откладывает другую | Сохранить разные статусы; не внедрять предложение и не терять отложенное |
| Тесты прошли, новое пожелание отсутствует в главном ТЗ | Не объявлять завершение; исправить документацию и сверить пожелания |
| Обычный ChatGPT не может изменить исходный документ | Выдать обновлённый файл/патч и явно назвать не обновлённый источник |
| Уже есть spec, план и AGENTS.md | Использовать и дополнять их, не заменять вслепую |
| Тест выявил проблему | Исправить реализацию, сохранив валидное требование |
| Внешняя система недоступна | Назвать непроверенный путь и доступное доказательство |
| Продолжить старый чат | Сохранить принятые решения и прочитать актуальные файлы |

Перед завершением проверить, что заявленные команды реально выполнялись,
покрытие соответствует выводам и критерии приёмки не подменены наличием файлов.
Навык не разрешает публикацию, сообщения другим людям или разрушительные
операции вне разрешённой пользователем области.
