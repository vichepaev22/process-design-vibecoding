# Privacy

Process Design Vibecoding is an instruction-based plugin. It has no developer
hosted service, MCP connection, authentication, telemetry or automatic data
upload. Its optional Python helpers read or create local project documents;
they do not make network requests.

When a host assistant uses the skill, project material is processed by that
host and any tools the user authorizes. Their respective privacy policies and
workspace controls apply. This package grants no additional tool access.

Version 1.2.0 instructs the host to use an available Context7 tool for current
documentation. Relevant technology names, versions and lookup questions are
sent through that host-provided connection under its applicable privacy rules.
The instructions do not require sending credentials or private source code,
and the package does not establish a Context7 connection itself.

GitHub issues are public. Do not post credentials or private project material.
For package questions, use the repository's issue tracker.
