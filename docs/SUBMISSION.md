# Подача в публичный каталог OpenAI

Для результата «открыл ChatGPT → нашёл плагин → установил» необходима одобренная
публичная карточка. GitHub служит исходником и местом скачивания пакета.

## Что подготовлено

- Переносимый `plugin.json`, имя и версия, короткое и полное описание.
- Один навык с шаблонами и справочными материалами; без MCP и секретов.
- Иконка, ссылки на продукт, поддержку, privacy и terms.
- Plugin ZIP с манифестом в корне, changelog и контрольные суммы релиза.
- Инструкция короткой ручной проверки: `docs/INSTALL_CHATGPT.md`.

## Следующие действия владельца developer identity

1. Войти в [Plugins dashboard](https://platform.openai.com/plugins).
2. Выбрать Upload new or existing plugin и **подтверждённую developer identity**.
   Отображаемое имя издателя должно соответствовать этой identity; при
   необходимости обновить метаданные пакета. Право подачи зависит от роли
   организации; верификация личности или организации выполняется владельцем.
3. Загрузить `process-design-vibecoding-plugin-1.2.0.zip` из релиза.
4. Проверить Metadata & Skills, устранить обязательные замечания и загрузить
   исправленную версию. Для пакета только с навыком MCP review не нужен.
5. Выполнить короткий тест в доступном интерфейсе и сохранить фактические результаты.
6. Submit for review. После одобрения выбрать Publish и проверить публичную
   карточку и установку в обычном ChatGPT.

Автоматические локальные проверки не заменяют проверки OpenAI. Одобрение,
доступность по планам/регионам и сроки не гарантируются. Для изменения навыка
после публикации требуется новый ZIP.
