# Установка в обычный ChatGPT

Это плагин с одним навыком. Он предназначен для обычного чата ChatGPT, а также
Codex. Work не требуется для самого алгоритма; доступные инструменты и способы
установки определяются аккаунтом и правилами рабочего пространства.

## Общий каталог

После одобрения и публикации автором пользователь открывает
[каталог плагинов](https://chatgpt.com/plugins), находит Process Design Vibecoding,
устанавливает и выбирает его через `@` в новом диалоге. Проверить доступность
для конкретного аккаунта можно только по фактической опубликованной карточке.

**Текущий статус этого проекта:** пакет подготовлен для подачи; наличие
репозитория и ZIP не означает одобрения или появления карточки в каталоге.

## GitHub-импорт в рабочее пространство

Если у вас есть соответствующий административный доступ:

1. Откройте Admin Console → нужное рабочее пространство → Plugins → Add →
   Import marketplace.
2. В Source укажите `https://github.com/vichepaev22/process-design-vibecoding`.
3. Path оставьте пустым: `.agents/plugins/marketplace.json` находится в корне.
4. Для обновлений оставьте Branch пустым либо выберите `main`. Для фиксации
   версии укажите тег `v1.3.0`.
5. Выполните импорт, предоставьте GitHub доступ по запросу и проверьте результат.
6. Настройте доступ к плагину в рабочем пространстве. Затем установите его в
   каталоге и выберите через `@` в обычном диалоге.

Импорт и доступность проверяются на стороне ChatGPT. Пакет не содержит MCP,
который мог бы потребовать настольный интерфейс. GitHub-импорт не обходит
ограничения тарифа и рабочего пространства.

## Загрузка ZIP

Если для вашего рабочего пространства доступна загрузка плагинов, откройте
Admin Console → Plugins → Add → Upload plugin и выберите **plugin ZIP** из
релиза. Не выбирайте skill ZIP и стандартный GitHub Source code ZIP: у них
другая структура. Завершите проверки и настройте доступ.

Если такого пункта нет, этот способ недоступен для текущей роли или аккаунта;
наличие ZIP его не включает.

## Короткая проверка после установки

В новом чате выберите плагин и дайте запрос:

> Основное ТЗ — прикреплённый PRD. Добавь уведомление после подтверждённого
> начисления. Сначала обнови ТЗ, затем приёмку и план. Отдельно сохрани как
> предложение идею истории уведомлений. Покажи статусы изменений.

Проверьте: основное ТЗ обновлено или выдан явный патч; предложение не принято
молча; реализация не названа проверенной без результатов. Затем дайте короткое
уточнение в том же диалоге и проверьте сохранение текущего контекста.
Это инструкция будущего smoke-теста; в данном релизе ChatGPT-тест не выполнен.
